# 网页抓小球小游戏 · 开发任务清单（tasks.md）

> 依据：spec.md v1.0 ｜ 状态：待用户确认
> 流程约定：每个任务按"人工验收清单 → 编码实现 → 代码评审 → 浏览器人工验证"推进，一次只做一个任务，验证通过才进入下一个。

---

## 任务 1：静态页面骨架与样式

**目标**：搭建 index.html（顶栏 + 游戏区两段结构）与 style.css（浅黄背景、Flex 顶栏、按钮样式、引导文字），不含任何 JS 逻辑。

**人工验收清单（浏览器验证）**
1. 打开 index.html → 页面背景为浅黄色。
2. 顶部信息栏横向排列 3 个元素：分数（初始 0）、倒计时（初始显示 02:00）、【开始游戏】按钮，有明显视觉区分。
3. 游戏区占据信息栏以下全部剩余高度（缩放窗口高度，游戏区自适应）。
4. 游戏区中央显示引导文字"点击【开始游戏】按钮开始挑战"。
5. 点击按钮无任何反应（尚未绑定事件）。

---

## 任务 2：游戏状态控制与 2 分钟倒计时

**目标**：script.js 实现开始按钮事件、游戏状态标记（未开始/进行中/已结束）、`setInterval` 倒计时（`mm:ss` 每秒递减）、归零结束。

**人工验收清单**
1. 点击开始 → 按钮变为禁用（置灰不可点）。
2. 引导文字消失，倒计时从 02:00 开始每秒递减（01:59 → 01:58 …）。
3. 倒计时归零后停止递减，显示"时间到！"提示。
4. 刷新页面可重复测试。

---

## 任务 3：小球生成、随机位置与点击补充

**目标**：实现 `createBall()`——蓝色圆形 div、随机直径 40~70px、随机位置（用 `getBoundingClientRect` 计算游戏区尺寸，保证球完整在可视区内）；游戏开始生成 3 个；点中球消失并在新随机位置补充 1 个；游戏结束清除全部球。

**人工验收清单**
1. 点击开始 → 同屏出现且仅出现 3 个蓝色圆形小球，尺寸肉眼可见有差异（40~70px）。
2. 球均完整显示：反复开局多次，无任何球被右边界/底边界截断、不压住顶栏。
3. 点中任意球 → 该球立即消失，同时在另一随机位置出现 1 个新球，同屏始终 3 个。
4. 倒计时归零 → 3 个球全部消失。

---

## 任务 4：计分系统（事件委托 + 冒泡阻断）

**目标**：计分点击监听绑定在游戏区容器上（事件委托）；点球 `stopPropagation` 阻断冒泡 → +2；点空白 −1；允许负分；顶部分数实时刷新；未开始时点击不计分。

**人工验收清单**
1. 点中球 → 分数 +2 并立即刷新显示。
2. 点游戏区空白 → 分数 −1 并立即刷新显示。
3. 连续空白扣分至负数 → 分数正确显示负值（如 −3）。
4. 点中球时不会同时触发空白扣分（分数只 +2，不出现 +2 后又 −1）。
5. 点击顶部信息栏 → 分数不变。
6. 未开始时在游戏区点击 → 分数保持 0。

---

## 任务 5：飘字反馈与倒计时告警动画

**目标**：CSS keyframes 实现飘字（点击处生成 span，绿 `+2` / 红 `−1`，上飘渐隐 0.6s，动画结束移除 DOM）；剩余 ≤10 秒时倒计时文字变红并闪烁。

**人工验收清单**
1. 点中球 → 点击位置浮现绿色 `+2`，向上飘动并渐隐消失，约 0.6 秒。
2. 点空白 → 点击位置浮现红色 `−1`，同样动画。
3. 连续快速点击多次 → 每次都有独立飘字，无残留堆积。
4. 倒计时进入最后 10 秒（含 10s，即显示 00:10 起）→ 倒计时数字变红色并闪烁。
5. 游戏结束重开后 → 倒计时恢复正常颜色。

---

## 任务 6：游戏结束与重开流程（状态重置串联）

**目标**：归零时显示"时间到！最终得分 X"；按钮恢复可用；重开时完整重置（分数清零、倒计时 02:00、重新布 3 球、清除上一局残留定时器与告警状态）。

**人工验收清单**
1. 倒计时归零 → 顶部提示"时间到！最终得分 X"，X 与当前分数一致；球全部消失。
2. 结束后开始按钮恢复可点击。
3. 再次点击开始 → 分数归 0、倒计时重置 02:00 并正常递减、重新出现 3 个球。
4. 快速连点重开（结束 → 立即开始 → 再结束 → 再开始）3 次 → 无倒计时加速、无球残留、无双计时等异常。

---
