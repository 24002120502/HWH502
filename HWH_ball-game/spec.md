# 网页抓小球小游戏 · 需求规格文档（spec.md）

> 版本：v1.0 ｜ 状态：待用户确认 ｜ 课程：《高级网页设计》
> 技术栈：原生 HTML5 + CSS3 + JavaScript（零依赖，无框架）

---

## 1. 项目概述

一款单人网页反应类小游戏：页面随机出现蓝色圆形小球，玩家在 2 分钟倒计时内点击小球得分、误点空白扣分，锻炼鼠标反应速度。适用于课堂演示与课后练习。

---

## 2. 功能需求

### 2.1 游戏开始与倒计时
- 页面顶部信息栏含【开始游戏】按钮。
- 点击按钮后游戏开始，顶部同步显示 2 分钟（120 秒）倒计时，格式 `mm:ss`（如 `01:45`），每秒递减。
- 归零后游戏结束，顶部提示文字 **"时间到！最终得分 X"**（X 为本局得分）。
- 游戏结束后点击【开始游戏】重新开局（分数清零、重新倒计时、重新布球）。
- 游戏进行中【开始游戏】按钮置为禁用，防止重复开局。
- 不记录历史最高分（用户已确认：仅文字提示，无结算面板）。

### 2.2 小球生成规则
- 小球为**蓝色圆形**（纯色，如 `#1E6FE0` 系），带轻微立体感（可选：径向渐变高光）。
- 同屏**始终保持 3 个小球**：游戏开始时一次生成 3 个；点中任意一个后，该球消失并在**新随机位置立即补充 1 个**，维持总数 3。
- 小球直径**随机 40~70px**（每个球独立随机）。
- 出现位置：顶部信息栏以下的**整页剩余区域**内随机，位置计算需保证球完整显示在可视区内（不超出右边界和底边界）。
- 小球为**静止**出现（不飘动、不弹跳）。

### 2.3 点击与计分
| 点击对象 | 结果 |
|---------|------|
| 小球 | 得分 +2，该球消失并在新随机位置补充 |
| 游戏区空白处 | 得分 −1，允许负分，无下限 |
| 顶部信息栏 | 不计分、不响应游戏逻辑 |

- 顶部信息栏**实时展示当前分数**，得分变化立即刷新。
- 游戏未开始时：点击小球/空白**均不计分**（此时无球可点，空白点击也无效）。

### 2.4 视觉反馈
- **飘字提示**：点击处浮现 `+2`（绿色）或 `-1`（红色）文字，向上飘动并渐隐（CSS 动画，约 0.6s），动画结束后从 DOM 移除。
- **倒计时告警**：剩余最后 10 秒（含 10s）时，倒计时文字变**红色并闪烁**（CSS 动画）。

## 3. 页面布局与视觉规格

- **背景**：浅黄色（如 `#FDF6D8` 系，最终色值实现时可微调）。
- **顶部信息栏**：横向排列 3 个元素——分数、倒计时、【开始游戏】按钮；与游戏区有明显视觉区分（如下边框或底色差异）。
- **游戏区**：信息栏以外的全部剩余页面区域，高度自适应窗口。
- 未开始状态：游戏区中央显示引导文字（如"点击【开始游戏】按钮开始挑战"）。
- 布局使用 Flex 实现；窗口尺寸变化不做特殊处理（球已生成的位置不重算）。

## 4. 技术约束

- 原生 HTML + CSS3 + JavaScript，**不使用任何框架/库**。
- 文件结构（三文件分离）：
  ```
  网页抓小球游戏/
  ├── index.html
  ├── style.css
  ├── script.js
  └── spec.md
  ```
- 兼容范围：最新版 **Chrome / Edge / Firefox**（用户已确认，无需兼容 Safari 及旧浏览器）。
- 可放心使用：Flex 布局、ES6+（`let/const`、箭头函数、模板字符串）、CSS3 动画、`setInterval`、`getBoundingClientRect`。
- 事件机制要点：计分点击监听绑定在**游戏区容器**上（利用事件对象坐标判断），小球点击使用 `stopPropagation` 阻断冒泡，避免"点中球又被空白扣分"。
- JS 代码需有中文注释，命名规范，便于课堂讲解。

## 5. 验收标准总览（最终整体验收）

1. 打开页面 → 浅黄背景、顶部栏可见、无小球、有引导文字。
2. 点击开始 → 出现 3 个蓝色球、倒计时从 02:00 递减、按钮禁用。
3. 点中球 → 分数 +2、点击处飘绿字 `+2`、球数仍为 3 且至少一个换了新位置。
4. 点空白 → 分数 −1、飘红字 `-1`。
5. 分数可以为负数。
6. 剩余 10 秒 → 倒计时变红闪烁。
7. 倒计时归零 → 提示"时间到！最终得分 X"，球全部消失。
8. 再次点击开始 → 全部状态重置、重新开局。
9. Chrome / Edge / Firefox 最新版均正常。
