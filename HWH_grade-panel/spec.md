### A. 新增「各科平均分」模块
- 位置：统计卡区域下方、数据操作区上方。
- 内容：5 个科目各一行——科目名（左）+ 渐变进度条（蓝→青，宽度 = 平均分百分比）+ 平均分（右，1 位小数）。

- 参考数值（手算锚点）：语文 82.4、数学 84.2、英语 83.1、网页设计 87.4、数据库 82.9。

### B. 数据操作区新增筛选按钮组
- 在排序按钮组右侧新增第二组按钮：**全部 / 优秀 / 含不及格**。
- **三态互斥**：任一时刻只有一个高亮，默认「全部」。
  - 全部 = 不过滤；优秀 = 平均分 ≥ 85（EXCELLENT_AVG）；含不及格 = 有挂科科目。
  - ⚠ 口径勘误（已确认 A 规则）：data.js 注释称优秀 7 人，但按"平均≥85"规则张明轩（90.2）同样满足，**实际为 8 人**，以规则为准。
- **与搜索、排序叠加**：数据流 = 搜索 → 筛选 → 排序（`refresh` 内串联）。
- 考察点：filter / sort / querySelectorAll / classList / 事件委托（按钮组复用模板的委托写法）。

### C. 新增「榜单与预警」区
- 位置：数据操作区下方、学生卡片区上方。
- **顶部红色横幅**：`⚠ 班级中存在不及格科目，请关注预警名单中的学生。`
  - **按全班判断**：全班有挂科即显示（本数据恒显示），与筛选无关。
- 三列卡片（Grid 三栏）：
  1. **优秀学生 Top3（平均≥85）**：按均分降序取前 3；行 = 名次圆徽（1/2/3 金/银/铜或统一色）+ 姓名（学号）+ 均分（蓝色）。参考：周诗涵(2024008) 97.8、陈雨桐(2024004) 95、许若曦(2024018) 95。

## 1. 项目概述

在课程起始模板的 `<script>` 中补全 5 个函数 + 4 个工具函数，实现一个学生成绩分析面板，与 target.html 渲染效果一比一还原。

## 2. 数据来源与结构（真实 data.js 已确认）

- `window.SUBJECTS`：`[{ key, name, abbr, full }]`，五门科目：
  | key | name | abbr | full |
  |-----|------|------|------|
  | chinese | 语文 | 语 | 100 |
  | math | 数学 | 数 | 100 |
  | english | 英语 | 英 | 100 |
  | web | 网页设计 | 页 | 100 |
  | database | 数据库 | 库 | 100 |
- `window.STUDENTS`：`[{ id, name, gender, chinese, math, english, web, database }]`，共 **18** 名学生。
  - `id`：学号字符串（7 位，如 "2024001"）
  - `gender`：**`"男"` / `"女"`**（注意：非 boy/girl！头像类需映射：男 → `boy`，女 → `girl`）
  - 分数：0~100 整数
- 常量：及格线 `PASS_LINE = 60`。
- 数据内置边界场景（用于验收）：挂科学生 3 人（刘子涵语58、孙博文数55、黄宇轩英58）、满分 1 处（周诗涵语100）、优秀学生 7 人（平均≥85）。

## 3. 功能需求（5 项必做）

### 3.1 班级概览统计 `renderStats(list)`
- 用 `reduce` 求 list 全部学生五科分数总和 → 总分。
- 平均分 = 总分 ÷（人数 × 科目数），保留 1 位小数。
- 用 `filter` 统计**无不及格科目**的学生数，及格率 = 该人数 ÷ 总人数 × 100，**取整**（口径已确认）。
- 用 `getElementById` 写入 4 张统计卡：`statCount` / `statTotalScore` / `statAvgScore` / `statPassRate`。
- `statPassRate` 内部已有 `<span class="stat-unit">%</span>`，用 `.firstChild.textContent = passRate` 只改数字，不动 % 符号。

### 3.2 学生卡片列表渲染 `renderStudentCards(list)`
- 遍历 list，用 `createElement` + `appendChild` 生成 `.student-card` 卡片，写入 `#studentList`（先清空）。
- 每张卡片结构：
  - 头部 `.hd`：`.avatar`（gender 映射：`"男"`→`boy` 类、`"女"`→`girl` 类，显示姓名首字）+ 姓名 `.name` + 学号 `.meta` + 排名徽章 `.rank-badge`
  - **排名 = 当前 list 中的序号 + 1；第 1 名徽章加 `gold` 类金色高亮**（已确认）
  - 分数网格 `.score-grid`：遍历 SUBJECTS 生成 5 个 `.score-item`（标签用 **abbr 缩写**：语/数/英/页/库 + 分数）；分数 < 60 加 `fail` 类（红色），满分（≥ sub.full）加 `full` 类（绿色）
  - 底部 `.ft`：总分（`.total`）+ 均分（`.avg`）
- 卡片设置 `setAttribute("data-id", s.id)`。

### 3.3 不及格预警 `renderFailWarning(list)`
- `filter` 筛出有不及格科目的学生 → `sort` 按不及格科目数**降序** → `forEach` 写入 `#failWarningList`。
- 每行 `.rank-row`：**名次 + 姓名（不及格科目名） + 总分**（已确认），如「1 张子墨（数学/物理/化学） 265」。
- 若无人不及格：写入 `<div class="empty">全员通过，无预警</div>`。

### 3.4 搜索 `search(keyword)`
- `keyword.trim().toLowerCase()`；无关键字返回 `STUDENTS.slice()`（全部，副本）。
- `filter`：姓名或学号包含关键字即保留（忽略大小写）。
- input 事件已带 200ms 防抖（模板已给，无需修改）。

### 3.5 排序 `sortList(list, by)`
- `list.slice()` 复制后排序，**不修改原数组**。
- `by === "total"`：按总分降序 `getTotal(b) - getTotal(a)`。
- `by === "id"`：按学号升序 `a.id > b.id ? 1 : -1`。
- 按钮切换高亮（`classList` + 事件委托）模板已给，无需修改。

### 3.6 工具函数（先行实现）
- `scoreClass(v)`：v < 60 → `"fail"`；v >= 100 → `"full"`；否则 `""`（配合 sub.full 判断满分）
- `getTotal(s)`：`SUBJECTS.reduce` 累加五科分数
- `getAvg(s)`：总分 ÷ 5，保留 1 位小数
- `getFails(s)`：`SUBJECTS.filter` 分数 < 60 的科目数组
- `firstName(s)`：`s.name.charAt(0)`（模板已给）
- `avatarClass(gender)`：性别映射——`"男"` → `"boy"`、`"女"` → `"girl"`（真实数据为中文性别，必须映射）

## 4. 技术约束

- 只修改 starter-level1.html 中 `<script>` 内的 TODO 区域；**HTML 结构、CSS、事件绑定代码一律不动**。
- 原生 JavaScript（ES5/ES6 混用与模板风格保持一致，模板用 `var` + function 表达式处跟随模板）。
- 必须使用考察点要求的数组方法：`reduce / filter / sort / forEach / slice / map`。
- 兼容最新版 Chrome / Edge / Firefox。
- 代码保留/补充中文注释，便于课堂讲解。

## 5. 验收标准

1. 打开页面 → 4 张统计卡显示正确：人数 18、总分、平均分（1 位小数）、及格率（整数 + %）。
2. 默认按总分降序渲染 18 张学生卡片；第 1 名（周诗涵，总分 489）徽章金色；不及格分数红色（刘子涵语58/孙博文数55/黄宇轩英58）、周诗涵语文 100 绿色。
3. 不及格预警列表 3 人：刘子涵、孙博文、黄宇轩（各挂 1 科，次序按 sort 稳定性），每行含名次、姓名、挂科科目名、总分。
4. 搜索框输入姓名片段或学号 → 列表、统计卡、预警实时联动过滤；清空恢复全部。
5. 点击「按学号↑」→ 按学号升序重排且按钮高亮切换；点回「按总分↓」恢复。
6. 搜索 + 排序可叠加生效（先搜后排）。
7. 控制台无任何报错。
